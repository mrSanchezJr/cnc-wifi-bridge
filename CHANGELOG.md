## [1.0.0] — 2026-10-29

### 🚀 Добавлено (Added)
- **Единый универсальный мост Wi-Fi <-> TCP <-> UART для контроллеров ЧПУ** (Inectra MSC-3US, GRBL и совместимых).
- **Поддержка микроконтроллера ESP-01 / ESP-01S (ESP8266)**:
  - Частота CPU 160 МГц (вдвое выше стандартной) для максимальной отзывчивости.
  - Работа через аппаратный UART0 (`Serial`, GPIO1 TX, GPIO3 RX) без паразитного отладочного мусора в линию станка.
  - Опциональный отладочный вывод в UART1 (`Serial1` на GPIO2 TX).
  - Аппаратные кольцевые буферы 1024 байта, экономное потребление RAM (36%).
- **Поддержка микроконтроллеров ESP32 (ESP-32S, ESP-WROOM-32, NodeMCU-32S)**:
  - Частота CPU 240 МГц.
  - Использование независимого аппаратного UART2 (GPIO 16 RX2, GPIO 17 TX2) для станка.
  - Сохранение свободного USB порта UART0 (COM-порт) для мониторинга и отладки.
- **Сетевой стек и низкая задержка**:
  - TCP-сервер (порт 8088 по умолчанию) с отключением алгоритма Нагла (`setNoDelay(true)`).
  - Мгновенная отправка статусов ЧПУ на ПК через `client.flush()`.
  - Автоматическое вытеснение зависших TCP-сессий при повторном подключении управляющей программы.
- **Режимы подключения Wi-Fi**:
  - **Режим станции (STA)**: подключение к существующей сети Wi-Fi с настраиваемым тайм-аутом.
  - **Резервная точка доступа (AP)**: автоматический запуск сети `Inectra-CNC-Bridge` (пароль `12345678`, IP `192.168.4.1`), если роутер недоступен.
  - Возможность фиксации статического IP-адреса.
- **Беспроводная прошивка (ArduinoOTA)**:
  - Возможность обновления прошивки микроконтроллеров по Wi-Fi без подключения кабелей.
- **Интеграция с PlatformIO**:
  - Окружения `[env:esp01]` и `[env:esp32]` в едином файле конфигурации `platformio.ini`.
