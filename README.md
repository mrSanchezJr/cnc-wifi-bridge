# CNC Wi-Fi TCP Serial Bridge (ESP-01 & ESP32)

[![PlatformIO](https://img.shields.io/badge/PlatformIO-ESP32%20%7C%20ESP8266-orange.svg)](https://platformio.org/)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE.txt)

Универсальная микропрограмма (прошивка) для микроконтроллеров **ESP-01 / ESP-01S (ESP8266)** и **ESP32 (ESP-32S, ESP-WROOM-32)**, превращающая модуль в высокоскоростной прозрачный беспроводной мост **Wi-Fi (TCP Server) <-> Hardware UART** для ЧПУ контроллеров **Inectra MSC-3US**, GRBL и совместимых систем.

Совместима с управляющими программами [.NET Windows Forms (G-write, gpellers)](https://github.com/mrSanchezJr) без необходимости установки сторонних виртуальных COM-портов.

---

## 📋 Особенности и возможности

- ⚡ **Низкая задержка передачи**:
  - Отключение алгоритма Нагла (`setNoDelay(true)`) на TCP-сокете.
  - Немедленная отправка ответов станка на ПК через `client.flush()`.
  - Разогнанные частоты ядер: **160 МГц** для ESP-01 и **240 МГц** для ESP32.
- 📡 **Два режима Wi-Fi**:
  - **Клиент сети (STA)**: автоматическое подключение к домашней / цеховой сети Wi-Fi.
  - **Резервная точка доступа (AP)**: если роутер выключен или недоступен, модуль автоматически поднимает собственную защищенную сеть `Inectra-CNC-Bridge` (IP `192.168.4.1`, порт `8088`).
  - Опциональная фиксация статического IP-адреса.
- 🛡️ **Надежность и защита от зависаний**:
  - Автоматическое вытеснение старой сессии: при перезапуске программы на ПК модуль мгновенно переподключает сокет.
  - На ESP-01 рабочий порт станка изолирован от отладочных сообщений: в контроллер ЧПУ поступают только «чистые» G-код команды.
- 🔄 **Беспроводная прошивка (ArduinoOTA)**:
  - Возможность обновлять прошивку «по воздуху» после первоначальной установки на станок.

## 🛠️ Схемы подключения к контроллеру Inectra MSC-3US

### 1. Подключение ESP-01 / ESP-01S (ESP8266)

> [!WARNING]
> **Питание ESP-01 строго 3.3 В!** Подключение питания 5 В к выводу VCC модуля ESP-01 выведет его из строя. Линии UART (TX/RX) кратковременно толерантны к 5 В, но для VCC используйте стабилизатор 3.3 В (например, AMS1117-3.3 или вывод 3.3 В контроллера).

| Вывод ESP-01 / ESP-01S | Подключение к Inectra MSC-3US | Примечание |
|---|---|---|
| **VCC** | **+3.3V** (через стабилизатор 3.3 В от +5 В) | **Не подавать 5 В!** |
| **GND** | **GND** | Общий провод «земли» (обязательно) |
| **CH_PD (EN)** | **+3.3V** | Разрешение работы чипа (подтяжка к VCC) |
| **TX (GPIO 1)** | **RX** контроллера Inectra | Передача команд в станок |
| **RX (GPIO 3)** | **TX** контроллера Inectra | Прием ответов от станка |
| **GPIO 0** | Оставить свободным | (Замыкается на GND **только** при прошивке) |
| **GPIO 2** | Оставить свободным | (Опционально: вывод логов `Serial1` при `DEBUG_TO_SERIAL1 = true`) |
| **RST** | Оставить свободным | Сброс (подтянут внутри) |

---

### 2. Подключение ESP-32S / ESP32 (ESP-WROOM-32)

На ESP32 для станка задействован отдельный аппаратный **UART2**, благодаря чему основной USB-порт (UART0) остается полностью свободным для вывода отладочных логов в монитор порта.

| Вывод ESP-32S | Подключение к Inectra MSC-3US | Описание |
|---|---|---|
| **VIN / 5V** | **+5V** | Питание модуля (от станка или внешнего БП) |
| **GND** | **GND** | Общий провод «земли» (обязательно) |
| **GPIO 16 (RX2)** | **TX** контроллера Inectra | Прием данных от контроллера ЧПУ |
| **GPIO 17 (TX2)** | **RX** контроллера Inectra | Передача команд в контроллер ЧПУ |

## ⚙️ Настройка параметров перед прошивкой

Все сетевые параметры задаются в файле [`include/config.h`](include/config.h):

```cpp
// Имя и пароль вашей локальной сети Wi-Fi:
#define WIFI_SSID           "kyvartirad34"
#define WIFI_PASSWORD       "pa33-3e7"

// Порт TCP сервера (к нему подключается G-write / gpellers):
#define TCP_PORT            8088

// Резервная точка доступа (AP):
#define AP_SSID             "Inectra-CNC-Bridge"
#define AP_PASSWORD         "12345678"
```

## 🚀 Сборка и прошивка через PlatformIO

Проект полностью настроен для работы в среде **PlatformIO** (VS Code или CLI).

### 1. Компиляция прошивок

```bash
# Сборка прошивки для ESP-01 (ESP8266):
pio run -e esp01

# Сборка прошивки для ESP32:
pio run -e esp32
```

---

### 2. Прошивка ESP-01 через USB-адаптер CH340

На недорогих программаторах CH340 для ESP-01 (черный или желтый USB-свисток с колодкой 2x4) отсутствует автоматическая схема перевода в режим прошивки (DTR/RTS).

**Чтобы перевести ESP-01 в режим прошивки:**
1. **Если на адаптере есть микропереключатель `UART / PROG`**:
   - Переведите переключатель в положение **PROG**.
   - Вставьте адаптер в USB-порт.
2. **Если переключателя нет**:
   - Замкните пин **GPIO 0** на **GND** (например, пинцетом или перемычкой между ножками колодки).
   - Не размыкая, вставьте адаптер в USB-порт компьютера.
   - После подключения контакт можно разомкнуть — модуль уже находится в режиме загрузчика (UART Download Bootloader).

После этого выполните команду загрузки:
```bash
pio run -e esp01 -t upload
```

*(По умолчанию в `platformio.ini` задан порт `COM10` и скорость `115200`)*.

---

### 3. Прошивка ESP32

Для большинства плат ESP-32S / NodeMCU-32S прошивка выполняется автоматически:
```bash
pio run -e esp32 -t upload
```
*(Если автоматический вход в загрузчик не срабатывает, удерживайте кнопку **BOOT** на плате при начале подключения `Connecting...`)*.

---

## 📡 Прошивка «по воздуху» (OTA)

После первой прошивки кабелем модуль можно обновлять по Wi-Fi:
```bash
# Обновление ESP-01 по воздуху:
pio run -e esp01 -t upload --upload-port 192.168.1.150

# Обновление ESP32 по воздуху:
pio run -e esp32 -t upload --upload-port 192.168.1.150
```

Пароль OTA по умолчанию: `admin` (настраивается в `include/config.h`).
