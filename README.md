# CNC Wi-Fi TCP Serial Bridge (ESP-01 & ESP32)

[![PlatformIO](https://img.shields.io/badge/PlatformIO-ESP32%20%7C%20ESP8266-orange.svg)](https://platformio.org/)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE.txt)

Универсальная оптимизированная микропрограмма (прошивка) для микроконтроллеров **ESP-01 / ESP-01S (ESP8266)** и **ESP32 (ESP-32S, ESP-WROOM-32)**, превращающая модуль в прозрачный высокоскоростной беспроводной мост **Wi-Fi (TCP Server) <-> Hardware UART** для ЧПУ контроллеров **Inectra MSC-3US**, GRBL и совместимых систем.

Работает напрямую в режиме автономной точки доступа Wi-Fi **`Ultrank-CNC-Bridge`**, не требуя наличия внешнего роутера или сторонних виртуальных COM-портов.

---

## 📋 Особенности

- 🌐 **Автономная точка доступа по умолчанию**:
  - **Имя сети (SSID)**: `Ultrank-CNC-Bridge`
  - **Пароль**: `12345678`
  - **IP-адрес станка**: `192.168.4.1`
  - **TCP порт**: `8088`
  - Старт за доли секунды без ожидания внешних сетей.
- ⚡ **Максимальное быстродействие (Zero Overhead)**:
  - Отсутствие отладочного вывода и сторонних библиотек — 100% ресурсов отдано под кольцевой буфер и сокет.
  - Аппаратная линия UART полностью защищена от мусора — станок получает исключительно команды G-кода.
  - Отключение алгоритма Нагла (`setNoDelay(true)`) и немедленный сброс буфера `client.flush()`.
  - Тактовая частота: **160 МГц** (ESP-01) и **240 МГц** (ESP32).
- 🛡️ **Защита от зависших сессий**:
  - При повторном подключении или перезапуске управляющей программы на ПК старая сессия автоматически вытесняется новой.

## 🛠️ Схемы подключения к контроллеру Inectra MSC-3US

### 1. Подключение ESP-01 / ESP-01S (ESP8266)

> [!WARNING]
> **Питание ESP-01 строго 3.3 В!** Не подавайте 5 В на вывод VCC модуля ESP-01. Используйте стабилизатор 3.3 В (например, AMS1117-3.3 или вывод 3.3 В контроллера).

| Вывод ESP-01 | Подключение к Inectra MSC-3US | Описание |
|---|---|---|
| **VCC** | **+3.3V** (от LDO 3.3 В) | Питание модуля |
| **GND** | **GND** | Общий провод «земли» (обязательно) |
| **CH_PD (EN)** | **+3.3V** | Разрешение работы (подтяжка к VCC) |
| **TX (GPIO 1)** | **RX** контроллера Inectra | Передача команд в станок |
| **RX (GPIO 3)** | **TX** контроллера Inectra | Прием статусов от станка |
| **GPIO 0, 2, RST**| Оставить свободными | В штатном режиме не используются |

---

### 2. Подключение ESP-32S / ESP32 (ESP-WROOM-32)

На ESP32 задействован аппаратный **UART2** (GPIO 16 RX2 / GPIO 17 TX2).

| Вывод ESP-32S | Подключение к Inectra MSC-3US | Описание |
|---|---|---|
| **VIN / 5V** | **+5V** | Питание модуля (от станка или внешнего БП) |
| **GND** | **GND** | Общий провод «земли» (обязательно) |
| **GPIO 16 (RX2)** | **TX** контроллера Inectra | Прием данных от станка |
| **GPIO 17 (TX2)** | **RX** контроллера Inectra | Передача команд в станок |

## ⚙️ Настройки в `include/config.h`

Все ключевые параметры настраиваются в файле [`include/config.h`](include/config.h):
```cpp
#define AP_SSID         "Ultrank-CNC-Bridge"
#define AP_PASSWORD     "12345678"
#define AP_IP           192, 168, 4, 1
#define TCP_PORT        8088
#define UART_BAUD_RATE  115200
```

## 🚀 Сборка и прошивка через PlatformIO

```bash
# Сборка прошивок:
pio run -e esp01
pio run -e esp32

# Прошивка ESP-01 (подключенной к COM10):
pio run -e esp01 -t upload

# Прошивка ESP32 (подключенной к COM10):
pio run -e esp32 -t upload
```

---

## 💻 Подключение из управляющей программы (G-write / gpellers)

1. На компьютере или планшете подключитесь к Wi-Fi сети **`Ultrank-CNC-Bridge`** (пароль: `12345678`).
2. В программе выберите режим **Wi-Fi (TCP)**:
   - **IP адрес**: `192.168.4.1`
   - **Порт**: `8088`
3. Нажмите кнопку **«Подключить»**.
